## Data Overview

The data includes InSAR phase and Line-of-Sight (LOS) information, along with Pixel Offset Tracking (POT) results.

### Data Details

- **T33D**:
  - Start Date: 2025-03-19
  - End Date: 2025-03-31

- **T70A**:
  - Start Date: 2025-03-22
  - End Date: 2025-04-03

- **T106D**:
  - Start Date: 2025-03-24
  - End Date: 2025-04-05

- **T143A**:
  - Start Date: 2025-03-27
  - End Date: 2025-04-08

## Folder Structure

### Phase_Los:
Contains InSAR phase and LOS data, along with corresponding downsampled results and ENU direction vectors for each dataset.

- **Subfolders**:
  - `downsample`: Downsampled results.
  - `enu`: ENU direction vectors.
  - `phase_los`: InSAR phase and LOS data.

### Pixel Offset Tracking:
Contains results from Pixel Offset Tracking (POT) for each dataset, including azimuth and range data, downsampled results, and ENU direction vectors.

- **Subfolders**:
  - `azimuth_range`: Azimuth and range data.
  - `downsample`: Downsampled results.
  - `enu`: ENU direction vectors.
